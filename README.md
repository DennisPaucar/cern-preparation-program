# CERN Preparation Program

## Nombre del programa
CERN Preparation Program

## Objetivo personal
Mi objetivo con este programa es fortalecer mis conocimientos y habilidades en
Data Science, desarrollando una base sólida en análisis de datos, programación
y pensamiento estadístico que me permita aplicar estas competencias en
proyectos de investigación científica y análisis de datos a gran escala,
como los que se manejan en entornos como el CERN.

## Tecnologías y áreas a fortalecer
- Python (pandas, numpy, matplotlib, scikit-learn)
- Estadística y análisis de datos
- Git y control de versiones
- SQL y manejo de bases de datos
- Machine Learning
- Visualización de datos
